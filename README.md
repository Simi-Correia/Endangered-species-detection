# Leveraging Generative AI for Enhanced Endangered Species Detection and Conservation
This project aims to support wildlife conservation by classifying endangered animal species using Deep Learning and Generative AI. We used ResNet-18 and DenseNet-201 for image classification and applied Stable Diffusion to generate synthetic images for rare species.

## Overview
- Image classification using ResNet-18 and DenseNet-201 (with fine-tuning).
- Synthetic data generation using Stable Diffusion to enhance dataset size.
- Grad-CAM was used for visualizing model attention.
- Achieved over 95% validation accuracy with DenseNet-201.

## Dataset
The dataset includes ~6,600 cleaned and augmented images across 11 endangered species, sourced from public repositories like Kaggle, GitHub, and Hugging Face.

## Technologies Used
- Python, PyTorch
- ResNet-18, DenseNet-201
- Stable Diffusion (via Hugging Face)
- Grad-CAM for explainability
